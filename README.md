# Bilel Sahraoui — Portfolio

My portfolio as a full stack developer (Node.js • TypeScript): who I am, what I can do and the projects I have worked on, in English and French.

## What's inside

- **My projects** in a 3D carousel: panels set on a cylinder that bend as you scroll through them.
- **A case study per project**, each with its own theme: a Minecraft-style interface for my mods, a starry sky for Noxtys, an Azure portal look for Athlon.
- **My Cobblemon mods in 3D**: each mod has its own in-game item (Poké Ball, Safari Ball, Beast Ball, blocks, Shiny Charm…), and some balls send out Pokémon that roam around and cry when you click them.
- **My background, my stack and a contact form.**

## Stack

- **[Nuxt 4](https://nuxt.com)** (Vue 3) and **TypeScript**, as a prerendered static site
- **[Three.js](https://threejs.org)** for the project carousel and the 3D scenes, loaded only when needed
- **[@nuxtjs/i18n](https://i18n.nuxtjs.org)** for English and French
- **[Lenis](https://lenis.darkroom.engineering)** for smooth scrolling
- **Hand-written CSS**, no framework
- **[Fontsource](https://fontsource.org)** fonts: Bricolage Grotesque, Instrument Sans, Space Grotesk, JetBrains Mono, DM Mono

The site honours `prefers-reduced-motion`: without animations, the carousel and the 3D scenes give way to a simple version.
